# Telegram AI Agent — локальный помощник для анализа каналов

Локальный агент: вы задаёте задачу на русском языке → агент ищет в выбранных
Telegram-каналах → находит релевантные сообщения → извлекает точные
формулировки локальной AI-моделью → показывает источник и ссылку на оригинал.

Работает полностью локально на Windows 11, без платных API и VPS.

## Архитектура

```
Telethon Collector  ──┐
 (сбор сообщений)     │
                       ▼
                    SQLite (WAL)
                       ▲
                       │
aiogram Bot → Agent Core → Search Engine (keywords) → Ollama/Qwen3 (semantic) → Extractor
```

Bot и Collector — два независимых asyncio-таска в одном процессе (`main.py`).
Если один падает, ошибка логируется, но не обязательно роняет второй.

## Пошаговая установка

### 1. Установите Python
Скачайте и установите Python 3.11+ с [python.org](https://python.org).
При установке отметьте галочку **Add Python to PATH**.

### 2. Установите Ollama
Скачайте с [ollama.com/download](https://ollama.com/download) и установите.

### 3. Скачайте модель Qwen3 8B
Откройте командную строку и выполните:
```
ollama pull qwen3:8b
```
Это займёт время и ~5 ГБ места на диске.

### 4. Проверьте работу Ollama
```
ollama run qwen3:8b
```
Если модель отвечает на вопрос — всё работает. Введите `/bye`, чтобы выйти.

### 5. Установите зависимости проекта
Запустите `install.bat` (двойной клик или из командной строки).
Скрипт создаст виртуальное окружение и поставит все Python-пакеты.

### 6. Создайте Telegram-бота
1. Откройте [@BotFather](https://t.me/BotFather) в Telegram.
2. Отправьте `/newbot`, следуйте инструкциям.
3. Скопируйте выданный токен — это `BOT_TOKEN`.

### 7. Получите Telegram API ID/Hash
1. Откройте [my.telegram.org](https://my.telegram.org).
2. Войдите под своим номером телефона.
3. Перейдите в **API development tools**.
4. Создайте приложение, скопируйте `api_id` и `api_hash`.

### 8. Заполните `.env`
После `install.bat` появится файл `.env` (скопирован из `.env.example`).
Откройте его и заполните:
```
TELEGRAM_API_ID=ваш_api_id
TELEGRAM_API_HASH=ваш_api_hash
BOT_TOKEN=токен_от_botfather
```

### 9-10. Первый запуск и авторизация
Запустите `run.bat`. При первом запуске Telethon запросит в консоли:
- номер телефона;
- код из Telegram (придёт в само приложение);
- пароль двухфакторной аутентификации (если включена).

После этого создастся файл сессии `collector_session.session` — повторно
авторизовываться не понадобится.

### 11. Запустите приложение
`run.bat` (после первого раза можно просто запускать его).

### 12. Добавьте канал
Откройте вашего бота в Telegram, нажмите `/start` → **📡 Каналы** →
**➕ Добавить канал**, отправьте `@username` канала.

Работают только каналы, к которым у вашего аккаунта уже есть доступ
(публичные — всегда; приватные — если вы уже в них состоите).

### 13. Выполните первый поиск
**🔎 Новый поиск** → напишите запрос обычным русским языком, например:

> Найди за последние 7 дней сообщения о пожаре или повреждении НПЗ,
> вытащи точную формулировку и дай ссылку на оригинал.

## Структура проекта

```
telegram_ai_agent/
├── bot/            # aiogram: интерфейс, клавиатуры, состояния
├── collector/       # Telethon: сбор сообщений
├── agent/           # оркестрация поиска: разбор запроса, фильтр, анализ, сохранение
├── ai/               # AI provider (абстракция) + реализация Ollama + промпты + схемы
├── database/       # SQLite: модели, репозиторий, подключение (WAL)
├── config/          # настройки из .env
├── utils/            # логирование
├── tests/            # pytest
├── main.py
├── install.bat
├── run.bat
└── .env.example
```

## Защита от галлюцинаций

- Системный промпт запрещает модели использовать что-либо, кроме
  предоставленного текста сообщения.
- Ответ модели проверяется как строгий JSON (pydantic), невалидный —
  отбрасывается, результат не сохраняется.
- Дополнительно: если цитата, которую вернула модель, не встречается
  дословно в исходном тексте сообщения — результат отклоняется как
  вероятная галлюцинация (см. `agent/analyzer.py`).
- Ссылка на сообщение всегда строится программно из реальных
  `channel username` + `message_id`, а не генерируется моделью.

## Смена модели

Замените `OLLAMA_MODEL` в `.env` на, например, `qwen3:14b` (после
`ollama pull qwen3:14b`) — код менять не нужно, т.к. приложение общается
с моделью только через `ai/provider.py`.

## Смена AI-бэкенда: Ollama ↔ LM Studio

Приложение не привязано к конкретному провайдеру — переключение только через `.env`:

```
AI_BACKEND=lmstudio
LMSTUDIO_HOST=http://localhost:1234/v1
LMSTUDIO_MODEL=qwen3-8b
```

Настройка LM Studio:
1. Скачайте [lmstudio.ai](https://lmstudio.ai), установите.
2. Вкладка **Search** → найдите и скачайте модель (например, Qwen3 8B, GGUF).
3. Вкладка **Developer** → **Local Server** → выберите загруженную модель → **Start Server**.
   По умолчанию сервер поднимается на `localhost:1234`.
4. Скопируйте точное имя модели, как оно показано в LM Studio (обычно видно
   в интерфейсе сервера или через `GET http://localhost:1234/v1/models`),
   и укажите его в `LMSTUDIO_MODEL`.
5. В `.env` поставьте `AI_BACKEND=lmstudio`, перезапустите `run.bat`.

Важно: некоторые версии LM Studio/некоторые модели не полностью поддерживают
`response_format: json_object`. Если в логах видите ошибку от LM Studio —
это будет видно в `logs/agent.log` с телом ответа сервера; в таком случае
JSON-парсинг всё равно попытается извлечь JSON из обычного текстового ответа
(см. `_extract_json` в `agent/analyzer.py` и `agent/query_parser.py`).

## Что дальше (не реализовано в MVP, но заложена архитектура)

- Semantic/vector search (embeddings) поверх таблицы `messages`.
- Фоновый мониторинг с уведомлениями (`collector/message_collector.py`
  уже собирает новые сообщения циклично — не хватает только шага
  сравнения с правилами и алерта).
- Экспорт результатов в CSV/Excel/Word.
- Подключение других локальных моделей через тот же `AIProvider`.

## Безопасность

- `.env` и `*.session` в `.gitignore` — никогда не коммитятся.
- Секреты не пишутся в логи (`utils/logger.py`).
- Агент не пытается получить доступ к приватным каналам, в которых
  аккаунт не состоит, и не обходит ограничения Telegram.
